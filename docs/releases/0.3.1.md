# rmdex 0.3.1

本版本汇总 0.3.0 之后的交互改进、员工通信与连接和通知修复。

## 更新内容

- 消息长按支持重试、复制和从历史回答创建分支；AI 回答复制只包含最终回答。
- 缩小消息操作菜单，并将菜单定位到消息气泡旁；简化命令执行摘要。
- 员工支持异步定向通信，消息进入接收员工当前 Thread 队列；改进移动端布局与外部链接体验。
- 员工更换绑定 Thread 前增加确认弹窗。
- 改进 PC 到 Codex shared connection 的恢复处理。
- Relay 持久化任务完成监听并在重启后恢复，减少完成通知丢失和重复投递。
- Android 支持通知凭证校验及重新注册、初始化并发保护和 64 位通知游标传递，并处理后台服务超时回调。

## 安装包与限制

- Windows x64：`rmdex-pc-0.3.1-win-x64.msi`。
- Android：`rmdex-android-0.3.1-debug.apk`，包名 `xyz.kyeai.rmdex`，versionCode 为 4；沿用 debug 签名构建，未切换正式签名。
- Android 后台通知、锁屏、划掉应用、系统回收及点击返回 Thread 尚未完成端到端验收。当前后台连接仍受 Android 前台服务时限和系统策略影响，本版本不代表通知稳定性验收通过。
- 新增通知状态接口及监听持久化依赖更新 Relay；本次 GitHub Release 不包含线上部署或本机安装更新，线上服务未部署这些修复时不能获得完整效果。
